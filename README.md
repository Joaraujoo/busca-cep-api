# 🔍 Busca CEP com API

Este projeto faz uma busca de endereço a partir do CEP digitado pelo usuário, utilizando a API pública ViaCEP.

## ✨ Funcionalidades
- Preenchimento automático de endereço com base no CEP
- Validação de campo
- Interface simples e responsiva

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript (Fetch API)
- API ViaCEP
